## Key Features  

- **zkLLM Privacy**: AI interactions secured with zero-knowledge encryption.  
- **zkAuth**: Zero-knowledge based wallet authentication.  
- **Injection-Proof Shell**: Protection against adversarial AI prompt manipulation.  
- **Wallet Automation**: Automated portfolio rebalancing, staking, yield farming, and liquidity provisioning.  
- **Vibe Trade Live Mode**: AI-powered real-time trading and adaptive strategy execution.  
- **MCP Server**: Multi-Chain Processing server for automated strategy design and orchestration.  
- **Custom Prompts & Labels**: Personalized AI-driven flows for each wallet.  
- **Onion Search Integration**: Secure, anonymous external data connectivity.  
- **Offchain Task Execution**: Market analysis, notifications, and automation beyond blockchain.  

---

## Technology Stack  

AgentZk is built on a robust and modular foundation:  

- **Blockchain**: Solana  
- **Smart Contracts**: Rust (Anchor Framework)  
- **Frontend**: React.js, Solana Wallet Adapter  
- **Backend**: Node.js, Express  
- **AI Integration**: Custom zkLLM models  
- **Storage**: IPFS, Arweave  
- **Security**: Zero-Knowledge Proof libraries, AI-injection protection layer  

---

## Architecture  

AgentZk employs a layered architecture designed for scalability and privacy:  

- **User Interface Layer**: Intuitive UI for wallet and AI task interactions  
- **AI Agent Layer**: zkLLM-powered agent handling prompts, scheduling, and execution  
- **API Layer**: REST/GraphQL endpoints for protocol and offchain data exchange  
- **Blockchain Layer**: Solana programs for wallet, trading, and liquidity actions  
- **Storage Layer**: Hybrid IPFS/Arweave solution for encrypted data persistence

## Getting Started  

### Prerequisites  

- Node.js v16+  

- Yarn or npm  

- Solana-compatible wallet (Phantom, Solflare)  

### Installation  

```bash

# Clone the repository

git clone https://github.com/inline-arc/AgentZk.git

# Navigate to project directory

cd AgentZk

# Install dependencies

npm install

# Start development server

npm run dev

```
